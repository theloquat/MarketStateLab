# ADR 0002：观测契约与历史可得性边界

日期：2026-11-04；状态：本批已采用。

官方资产是31条收盘价和8条国债收益率，不能生成OHLCV。收益率以百分数记录，4.25→4.30为5bp，不能当债券投资回报。负价格和负收益率原值保留；价格跨越非正值时百分比变化未知，20次滚动窗口重新预热。

原始观测日期、假设可用日期、系统处理时间分别保存。日期缺少精确时区与发布时间时，首版采用日期后2个自然日UTC可用，明确是B级重建假设。日历、匿名宏观和文本暂不进入主状态模型；原始推文时间优先created_at_twitter，但保留事后采集标志及全部时间列。

固定8个核心资产和16个特征。20个观测变化不是统一的20交易日；跨资产as-of按已可用的最新观测对齐，超过7自然日不沿用。没有有效新观测不凭空生成快照。没有快照的日期，前端概率图不连线补齐。

规则基线阈值预先固定。GMM仅使用截至训练截止的可用快照拟合标准化、权重及状态名称；在线推断读取冻结JSON，无pickle。状态概率不是未来涨跌准确率。未来追加不改变旧输入和同一冻结模型的旧结果，已有自动测试。

后果：未知时间不会因固定滞后变为认证PIT；无法声称当前全包严格无历史修订或采集偏差。模型命名、预测效果、预警有效性与HMM比较仍待C3–C4独立评估。
