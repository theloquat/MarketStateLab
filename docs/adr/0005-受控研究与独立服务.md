# ADR 0005：受控研究、因果 HMM 与独立服务

日期：2026-11-06。状态：已实现；本机验收范围和性能缺口见 release/ACCEPTANCE.md。

## 决策

赛事部署使用 Java Undertow 网关，数据 API、特征/模型 API、预警 API 为独立进程。Caffeine 缓存仅用于所有同角色用户均可读取的官方数据结果，角色隔离、300ms TTL、写操作失效。Redis 承担热状态、注销标识与已提交事件广播。JWT 为 30 分钟 HS256 会话，管理员、研究员、观察员权限分别检查，后端须持有内部网关令牌。所有服务只在本机映射端口，非公网生产安全声明。

HMM 拟合只读训练截止之前数据，PCA 和状态命名也在训练期冻结。推断使用逐日前向过滤而非全测试段后向平滑，过滤状态在 MySQL 持久化，恢复需从真实预热数据继续。保留 GMM 和固定价格规则对照，不以无监督状态概率宣称涨跌准确率或利润。

研究工具只允许数据质量、模型比较、验证区间阈值扫描、事件证据、价格/文本同窗消融、匿名宏观敏感性。模型只能提出一个受 schema 限制的任务，人工批准后才执行。没有任意代码/SQL/shell、交易、无人值守任务或自动付费重试。日调用和 token 预留在发请求前持久扣记，网络失败和输出失败也占预算。预留是 token 数量控制，不是人民币/美元费用保证；真实使用量按服务商回执保存。

官方 DeepSeek 连接显式关闭思考模式，保持 600 输出 token 上限。其他兼容服务不猜测供应商私有参数。第一轮真实测试默认思考模式耗尽 600 输出 tokens，已保留失败记录；修复后第二轮成功，共 1600 tokens。密钥只保存在忽略的本机 access 配置中，未进入源代码、日志或文档。

## 依据与代价

[DeepSeek 官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)：默认启用思考，可通过 thinking.type=disabled 关闭。研究规划只是小型受控结构任务，无需长推理预算。[官方 JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)说明应明确请求 JSON 并处理空输出或长度截断。本实现拒绝无效输出，不尝试从任意文字执行代码。

本机 120 用户首次 HTTP 压测未达到 50ms，保留基线；WS 测试是 Redis 发布到客户端接收，不能充当 Kafka/Flink 全链路时延。单机部署、单 broker/TaskManager 不提供硬件故障高可用。数据原始发布时间不明的分支只作条件性研究，不因工具或 LLM 生成解释而升级可信等级。

SQLite 是本地数据导入与离线参照目录，MySQL 是分布式运行、过滤状态、幂等与 outbox 的主库；ClickHouse 是可重建的分析物化层，MinIO 保存原始包、PDF、Parquet、模型与 Savepoint。不得将本地参照路径包装成分布式执行。
