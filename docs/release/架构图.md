数据库实体分布：赛事运行、结果、过滤状态和投递主事务在MySQL；文档/模型本地目录与离线参照在SQLite，原件/模型/检查点在MinIO，分析事实在ClickHouse，热状态可从主库重建。上述关系是领域关系，不宣称跨数据库外键约束。
