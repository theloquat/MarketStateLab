# 本机验收路线

打开 [市场状态实验室](http://127.0.0.1:18080/lab)。如果服务停止，在仓库根目录执行 `./scripts/contest.sh start`。使用 `./scripts/contest.sh credentials` 读取本机登录信息。

1. **数据与质量。** 核对官方 39 个资产、314,318 条市场观测、辅助资料、缺失项和历史数据截止时间。
2. **模型与特征。** 打开冻结 GMM 或 HMM/PCA，检查训练截止时间、特征与时间留出评价。
3. **历史回放。** 用已验收的 HMM 读取已有运行，或开启自己的回放。对照状态曲线、预警、原始行和运行进度。
4. **文本证据与研究。** 查找原始文档，创建免费质量审计任务，核对批准、执行和结果。
5. **运行监控。** 查看组件与待处理记录，下载原始验证报告。

详细命令和恢复边界见[使用与验收](使用与验收.md)。性能边界见[性能与测试报告](性能与测试报告.md)。
