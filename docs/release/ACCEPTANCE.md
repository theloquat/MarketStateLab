## 明确没有判为通过的指标

- [ ] 十万条/秒持续全链路容量：尚未验证；本轮按用户确认保留。
- [ ] 所有端到端长尾小于100ms：已测场景P95可小于100ms，P99仍有超标；不把分位数成绩当绝对上限。
- [ ] 所有API端点/全部长尾小于50ms：四个热查询正常负载P95通过，未覆盖所有端点，P99仍会超标。
- [ ] 多日高负载与跨主机容灾：未进行，单机多进程不等于多机高可用。

详细样本、硬件、测量起终点和失败基线见性能与测试报告。已验证计算、缓存/推送和页面指标也只对已测条件成立。模型效果没有胜过固定规则，不宣称盈利或保证获奖。
